How to use this catalogue / كيفية استخدام هذا الكتالوج

These entries are concept summaries, not final specifications. Before development, define target users, core workflows, permissions, data model, integrations, security, and MVP scope.

For sensitive domains (healthcare, banking, government, etc.), specialist security and regulatory review are required. Prototypes must be distinguished from production systems.

Suggested next step: define the primary user, key workflow, data model, and out-of-scope boundaries for the first release.
